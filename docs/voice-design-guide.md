# 如何写好音色描述（Voice Design Prompt）

## 一、基本原则

- **长度**：1-4 句话即可，不需要长篇大论。核心特征描述清楚比堆砌维度更重要。
- **语言**：中文或英文均可，用你最擅长、表达最精准的语言。
- **位置**：音色描述写在 API 请求中 `messages` 数组里 **`role: user`** 的 `content` 字段。

## 二、建议覆盖的维度

你可以根据需求选择性地描述以下几个维度（不必全部涵盖）：

| 维度 | 说明 | 示例 |
|---|---|---|
| **身份锚点** | 年龄段 + 性别，决定基频范围 | “一位年迈的东欧裔学者”、“元气满满的少女” |
| **声音质感** | 气息走向、共鸣位置、吐字方式、音色底色 | “低沉、略带嘶哑”、“声线清脆” |
| **性格气质** | 通过声音传递出的情绪倾向或人格特征 | “说话节奏缓慢”、“语尾带一点上扬” |
| **发声方式** | 如气息音、实声、嘶吼等具体发声技巧 | “气息略长”、“吐字从容不迫” |

## 三、优秀示例

```
一位年迈的东欧裔学者，低沉、略带嘶哑，说话节奏缓慢
元气满满的少女，声线清脆，语尾带一点上扬
一位六十岁左右的老年男性，低沉沙哑的嗓音带着浓重的胸腔共鸣，说话时气息略长，吐字从容不迫，偶有因年岁带来的轻微震颤
```

## 四、四条“不要”红线

| 红线 | 说明 | 反面例子 |
|---|---|---|
| ❌ **避免矛盾** | 不要同时要求互相冲突的特质 | “天真童音 + CEO 气场” |
| ❌ **避免后期效果词** | 不要写混响、回声、EQ、压缩等后期处理相关的词汇 | “带点混响的女声” |
| ❌ **避免模糊词** | 不要使用缺乏具体指向的笼统词汇 | “普通的”、“正常的”、“外国腔” |
| ❌ **文本要匹配音色** | `assistant` 中要念的文本，必须与 `user` 中描述的音色气质一致 | 用“温柔舒缓女声”去念激情体育解说 |

## 五、一句话心法

**把 `user` 消息当作这副嗓子的“身份卡”——只写这副声音本身长什么样（年龄、性别、共鸣、气息、质感、气质），不写场景、不写动作、不写这次要说什么；1-4 句，核心特征清楚比堆砌维度更重要。**
