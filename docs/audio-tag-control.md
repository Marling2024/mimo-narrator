# MiMo-V2.5-TTS 音频标签控制 · 笔记

> 适用文档：语音合成 v2.5 → 音频标签控制（导演模式）  
> 核心场景：角色配音、影视级内容生成等对语音表演要求较高的场合

---

## 一、模式定位

**导演模式**：通过在文本中嵌入「风格标签」+「音频标签」，对语音做精细控制。

- **整体风格标签** → 放在目标文本**开头**
- **细粒度音频标签** → 穿插在文本中间，做行内/词级控制
- 所有标签内容统一放在 `messages` 中 `role: assistant` 的 `content` 字段

---

## 二、风格标签（段落级 / 整体基调）

### 语法

```
(风格1 风格2)待合成内容
```

- **括号格式**：半角 `()`、全角 `（）`、方括号 `[]` 均可
- **多风格并列**：多个风格名放同一对括号内，**分隔符不限**（空格、顿号都行）
- **自定义风格**：列表外风格也可直接写，模型能理解开放文本描述

### 推荐风格维度

| 维度 | 示例 |
|---|---|
| 语速 | 变快、变慢 |
| 情绪 | 开心、悲伤、生气、压抑的愤怒、温柔但疲惫 |
| 角色扮演 | 孙悟空、林黛玉 |
| 风格变体 | 悄悄话、夹子音、台湾腔 |
| 方言 | 东北话、四川话、河南话、粤语 |

---

## 三、音频标签（细粒度 / 行内控制）

嵌在文本特定位置，用来精准控制某一句的语气、呼吸、停顿、状态等。**支持中英双语 + 开放描述**，同一段内可混用、可叠加。

### 常见标签示例

| 标签 | 作用 |
|---|---|
| `(紧张, 深呼吸)` | 多情绪组合 |
| `(语速加快)` | 速度变化 |
| `(小声)` | 音量控制 |
| `(长叹一口气)` | 叹息 |
| `(咳嗽)` | 环境/生理音 |
| `(沉默片刻)` | 停顿 |
| `(苦笑)` | 复合情绪+神态 |
| `(提高音量喊话)` | 爆发式呼喊 |
| `(极其疲惫, 有气无力)` | 状态描写 |

标签本身也是开放文本，不限于上表——`(模仿自信)` `(爆发, 愤怒压不住)` `(轻笑|带点释然)` 这类自由组合都能生效。

### 混用编排示例（来自官方发布稿）

> (调侃) 老张你当时不是说这条航线稳得很吗……  
> (模仿自信, 提高音量) "系统全绿，放心走。"  
> (突然停顿) ……现在呢？  
> (爆发, 愤怒压不住) 现在整艘船都在报警！你管这叫"放心"?!  
> (声音变轻) 不过……你看那外面，裂开的星云像在呼吸一样。  
> (急促|呼喊) 别断通讯！喂！再撑十秒！十秒!!  
> (低声|情绪塌陷般平静) ……算了。  
> (轻笑|带点释然) 也挺好，至少是一起看的。

---

## 四、与自然语言控制的区别

| 方式 | 用法 | 适用粒度 |
|---|---|---|
| 自然语言控制 | user message 里写一句指令，如"播报→低语→嘶吼转场" | 段落级、整段基调 |
| 标签控制（导演模式） | 在 assistant content 里嵌 `(风格)` / `(音频标签)` | 句子级 / 词级 / 字级（某字哽咽、拖音、气音） |

两种可并存：整体基调用自然语言指令，局部精修用行内标签。
